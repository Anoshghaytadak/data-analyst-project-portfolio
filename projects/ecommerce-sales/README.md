# E-commerce Sales Analysis

This project focuses on e-commerce sales trends, order performance, and customer purchases.

## Business questions

- Which category sells the most?
- Are customers buying more on weekdays or weekends?
- Which payment method is most used?
- What is the average order value?

## Files

- `ecommerce_analysis.py` — analysis logic
- `data/ecommerce_sales.csv` — sample dataset

## Tools

- Python 3
- CSV analysis
