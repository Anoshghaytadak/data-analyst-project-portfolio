# Finance Dashboard

This project focuses on financial health indicators such as revenue, expenses, profit, and budget comparison.

## Business questions

- Is the company profitable?
- Which categories increase expenses?
- Are actual numbers below or above budget?
- How is cash flow trending?

## Files

- `finance_dashboard.py` — Python logic
- `data/finance_data.csv` — sample financial dataset

## Tools

- Python 3
- CSV analysis
