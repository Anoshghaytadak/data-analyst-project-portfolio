# Marketing Campaign Performance Analysis

## Business question
Which marketing channels generate the strongest engagement, conversions, and return on investment?

## Analysis
- Calculate click-through rate (CTR)
- Calculate conversion rate
- Compare revenue and campaign ROI by channel

## Run the project

```bash
python3 marketing_campaign_analysis.py
```

## Skills demonstrated
- Marketing KPI design
- Rate and ROI calculations
- Channel comparison
- Business recommendations from campaign data

## Example recommendation
Use ROI and conversion rate together when reallocating campaign budget; a channel with high clicks is not automatically the most profitable.
