# HR Employee Attrition Analysis

## Business question
Which departments and work patterns are associated with employee attrition?

## Analysis
- Calculate the overall attrition rate
- Compare attrition across departments
- Compare attrition for employees who work overtime

## Run the project

```bash
python3 hr_attrition_analysis.py
```

## Skills demonstrated
- CSV data loading
- Grouped KPI calculations
- Attrition-rate analysis
- Turning workforce data into recommendations

## Example recommendation
If overtime employees show a higher attrition rate, HR should review workload, staffing, and manager support for those teams.
