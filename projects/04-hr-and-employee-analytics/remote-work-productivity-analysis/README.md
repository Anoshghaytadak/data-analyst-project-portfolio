# Remote Work Productivity Analysis

## Category
HR & Employee Analytics

## Business question
How can an analyst use data to measure performance, identify patterns, and recommend an improvement for **Remote Work Productivity Analysis**?

## Suggested analysis
- Define the business KPI and the decision it supports
- Clean missing values, duplicates, and inconsistent categories
- Compare performance over time, across segments, and against a target
- Explain the most important insight and its business impact

## Starter project

Run the included Python starter from the repository root:

```bash
python3 projects/04-hr-and-employee-analytics/remote-work-productivity-analysis/remote_work_productivity_analysis.py
```

The starter produces a reproducible analysis brief. Replace its sample rows with a real dataset from a trusted public source and add charts in Excel, Power BI, Tableau, SQL, or Python.

## Portfolio deliverables
- Cleaned dataset
- SQL queries or Python notebook
- KPI dashboard
- Three evidence-based insights
- One practical recommendation
