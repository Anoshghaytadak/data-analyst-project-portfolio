# Sales Performance Dashboard

This project analyzes sales performance using a sample retail dataset. It focuses on revenue, profit, product performance, and regional contribution.

## Business questions

- Which product generates the most revenue?
- Which region performs best?
- What is the overall profit margin?
- Which month had the strongest sales?

## Files

- `sales_dashboard.py` — Python script to load and analyze the sample data
- `data/sample_sales.csv` — sample dataset used for analysis

## Run it

```bash
cd projects/sales-performance
python3 sales_dashboard.py
```

## Example metrics

- Total Revenue
- Total Profit
- Average Order Value
- Best Product
- Best Region

## Tools

- Python 3
- CSV processing with built-in standard library
